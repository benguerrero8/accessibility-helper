# Accessibility Helper — Support

Accessibility Helper is a Google Docs add-on that provides tools for improving document accessibility.

## Available Features

The current version supports:

- Shifting a selected range of heading levels down by one.
- Converting Heading 6 to Normal text.
- Preserving heading formatting when shifting levels.
- Applying changes to the current document tab or all document tabs.

## How to Use Accessibility Helper

1. Open a Google Docs document.
2. Navigate to **Extensions → Accessibility Helper → Open Accessibility Helper**.
3. Select the starting and ending heading levels.
4. Enable or disable **Keep Style**.
5. Choose whether to modify the current tab or all document tabs.
6. Click **Shift Headings Down**.

## Reporting Problems

If you encounter a problem, please include:

- A description of the issue.
- The steps required to reproduce it.
- Any error messages displayed.
- The expected and actual results.

Please do not include confidential document contents or sensitive information in support requests.
