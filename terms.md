# Accessibility Helper — Terms of Service

**Last Updated:** October 1, 2026

### 1. Purpose

Accessibility Helper is a Google Docs add-on that provides tools for managing document structure and improving accessibility.

### 2. Availability

Accessibility Helper is currently intended for internal use within the authorized Google Workspace organization.

### 3. Use of the Application

Users are responsible for reviewing changes made to their documents. Certain operations may modify multiple headings or paragraph styles simultaneously.

Users should consider making a backup of important documents before performing large-scale changes.
