# Accessibility Helper — Privacy Policy

**Last Updated:** October 1, 2026

Accessibility Helper is a Google Docs add-on designed to help users improve document accessibility by managing heading structures and formatting.

### Information We Access

Accessibility Helper accesses the active Google Docs document when a user requests a formatting or accessibility operation.

The add-on may read and modify document headings, paragraph styles, and related formatting information to perform the requested operation.

### Data Collection and Storage

The current version of Accessibility Helper does not intentionally collect or store document contents, personal information, or usage data outside Google Workspace.

Document processing is performed using Google Apps Script and Google's document services.

### Data Sharing

Accessibility Helper does not intentionally transmit document contents to third-party services or external developer-operated servers.

### Data Retention

Accessibility Helper does not maintain a separate database of document contents. Changes to documents are saved within Google Docs and are subject to Google's applicable data retention policies.

### Changes to This Policy

This policy may be updated as new functionality is added to Accessibility Helper.
